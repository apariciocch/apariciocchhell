# Imágenes del sitio

Sube aquí los recursos visuales usando exactamente estos nombres:

## Imagen principal

- Archivo: `foto-perfil.jpg`
- Ruta final: `assets/foto-perfil.jpg`
- Uso: fotografía profesional del hero.
- Formato recomendado: JPG o WebP.
- Tamaño recomendado: 900 x 1100 px, orientación vertical.
- Peso máximo recomendado: 400 KB.
- Encuadre: rostro y hombros visibles, fondo limpio, buena iluminación.

## Opcionales para futuras secciones

- `foto-consulta.jpg`: imagen de un espacio profesional o de trabajo.
- `foto-aprendizaje.jpg`: recurso visual relacionado con aprendizaje o acompañamiento educativo.
- `logo.svg`: logotipo personal si decides reemplazar las iniciales AC.

No uses fotografías de pacientes, menores o terceros sin autorización. La página no incluye imágenes genéricas automáticamente: solo mostrará los archivos que subas a esta carpeta.
